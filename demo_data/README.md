# Synthetic fixtures

Generated by `generate_demo.py` from fictional parameters and fixed random seed 731904, anchored to 7 October 2026. No personal dashboard files were used. Real company or fund names are public labels; ownership, units, prices, costs, payments and history are invented.

These files are deliberately tracked so you can inspect and share the complete sample dataset. `settings.json` is an empty object. Demo runtime files are kept separately in `.demo-runtime/` and ignored by Git.

The launcher regenerates the same kind of sample data relative to the launch date, so recent periods stay populated. In the repository, transactions are split by month and CSV history by quarter, with file lists in `manifest.json`. `spending.json` contains the metadata and an index of the payment chunks. The normal single-file layout is regenerated automatically inside the demo runtime.

The optional SQL chunks contain only this synthetic dataset. `python build_supabase_seed.py` assembles them into one SQL file for a new, empty Supabase project.
